# Real-Time-Sensors-Monitoring-Station-Using-Periodic-Task-Scheduler

## 📌 Project Overview

The **Real-Time Sensors Monitoring Station Using Periodic Task Scheduler** is an embedded systems project designed to monitor multiple sensor parameters in real time using a periodic task scheduling mechanism.

The system collects data from different sensors, processes the readings, and displays the sensor information. A periodic task scheduler ensures that each monitoring task is executed at regular time intervals.

This project demonstrates the implementation of real-time task scheduling, sensor interfacing, and embedded system programming.

## 🎯 Objectives

- To monitor multiple sensor parameters in real time.
- To implement a periodic task scheduling mechanism.
- To interface different sensors with a microcontroller.
- To collect and process sensor data efficiently.
- To display real-time sensor readings.
- To improve system efficiency through periodic task execution.

## ⚙️ Technologies Used

- **Microcontroller:** LPC2129 (ARM7)
- **Programming Language:** Embedded C
- **IDE:** Keil µVision
- **Microcontroller Architecture:** ARM7
- **Communication:** GPIO and ADC
- **Display:** 16x2 LCD
- **Scheduling:** Periodic Task Scheduler

## 🔄 Working Principle

1. The microcontroller initializes the required GPIO, ADC, LCD, and timer peripherals.
2. The periodic task scheduler manages the execution of different sensor monitoring tasks.
3. Sensors provide input data to the microcontroller.
4. The ADC converts analog sensor signals into digital values.
5. The microcontroller processes the collected sensor data.
6. The LCD displays the sensor readings and system status.
7. Each monitoring task executes at its predefined periodic interval.
